# Terminal icon source

`terminal.png` is Apple's macOS Terminal application icon, requested for this
personal launcher. Source: Apple's Terminal User Guide asset CDN:
https://ipcdn-web.apple.com/assets/v2/web/39c3cf79-78d9-4c4b-b30c-64cac5415a89

Apple owns the icon; it is not relicensed by this repository. `Icon.ps1` builds
local Windows ICO sizes from this image during installation.
